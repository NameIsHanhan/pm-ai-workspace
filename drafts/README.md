# 📝 草稿区（Drafts）

> 本目录是工作草稿区，用于存放 AI 生成的初稿、快速记录和迭代试错中的文档。

---

## 📋 用途说明

- **AI 生成初稿**：使用工作流生成的第一版文档
- **快速记录**：灵感捕捉、会议速记、临时笔记
- **迭代试错**：方案探索、多版本对比、实验性内容

## 📁 组织方式

按 **日期 + 主题** 组织文件：

```
drafts/
├── 20260224-user-login-redesign-draft.md
├── 20260225-payment-flow-analysis-draft.md
├── 20260226-order-fields-draft.md
├── archive/           # 归档目录
│   └── 202602/        # 按月归档（可选）
└── README.md
```

### 命名格式

```
[YYYYMMDD]-[主题描述]-draft.md
```

## 📦 归档规则

1. **何时归档**：草稿定稿后，正式版已移入 `prds/` 或 `outputs/`
2. **归档位置**：移入 `archive/` 子目录
3. **归档方式**：可按月（`archive/202602/`）或按项目归档
4. **保留时长**：建议至少保留 3 个月，之后可酌情清理

## 💡 使用建议

1. 草稿不追求完美，重在快速记录和迭代
2. 在文档顶部标注状态（如：`状态：草稿 v0.1`）
3. 定稿后及时从草稿区移出，保持工作区整洁
4. 有价值的草稿模式可沉淀为模板（存入 `templates/`）

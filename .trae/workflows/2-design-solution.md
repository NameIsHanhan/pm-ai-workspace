# 🏗️ Phase 2：方案架构（Design Solution）

> 第二阶段工作流：基于需求分析，设计完整的产品解决方案。

---

## 🎯 目标

将需求分析转化为具体的产品方案，包括功能架构、交互设计、数据模型等。

## 📥 输入

- Phase 1 的需求分析文档
- 影响范围评估报告
- 用户故事清单
- 项目上下文（`context/` 目录）

## 📤 输出

- 功能架构设计（存放至 `drafts/`）
- 交互流程图（存放至 `assets/diagrams/`）
- 数据字段清单初稿（存放至 `drafts/`）

---

## 🔄 执行步骤

### Step 1：功能架构设计

**提示词模板**：

```
基于以下需求分析，请帮我设计功能架构。

【需求分析】
{引用 Phase 1 输出}

请输出：
1. 功能模块划分（树形结构）
2. 各模块核心功能点
3. 模块间的依赖关系
4. MVP 范围建议（分期策略）
```

### Step 2：交互流程设计

**提示词模板**：

```
请为以下功能设计详细的交互流程。

【功能模块】
{描述需要设计的功能模块}

【用户故事】
{引用相关用户故事}

请输出：
1. 主流程（用 Mermaid 流程图表示）
2. 页面流转关系
3. 关键交互节点说明
4. 异常处理流程
```

### Step 3：数据模型设计

**提示词模板**：

```
请为以下功能设计数据模型。

【功能架构】
{引用 Step 1 输出}

请输出：
1. 核心数据实体及其关系（ER 图，用 Mermaid 表示）
2. 字段清单（表格形式）：
   - 字段名（中文）
   - 字段名（英文）
   - 字段类型
   - 是否必填
   - 默认值
   - 说明/校验规则
3. 状态流转图（如有状态字段）
```

### Step 4：页面原型草案

**提示词模板**：

```
请基于以下交互设计，生成页面原型的 HTML 代码。

【交互流程】
{引用 Step 2 输出}

【字段清单】
{引用 Step 3 输出}

要求：
1. 使用 HTML + CSS（内联样式）
2. 采用 Ant Design 风格
3. 包含示例数据
4. 标注交互说明（作为 HTML 注释）
5. 响应式布局
```

---

## ✅ 完成检查清单

- [ ] 功能架构清晰完整
- [ ] 交互流程覆盖所有场景
- [ ] 数据模型合理
- [ ] 字段清单准确
- [ ] 页面原型可供评审
- [ ] 技术可行性已初步验证

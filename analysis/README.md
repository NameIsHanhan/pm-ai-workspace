# 📊 业务分析区（Analysis）

> 本目录用于存放各类业务分析文档，包括数据分析、流程推演和影响范围分析。

---

## 📁 子文件夹说明

| 目录 | 用途 | 典型内容 |
|------|------|----------|
| `data-analysis/` | 数据分析 | 用户行为分析、业务数据报告、A/B 测试分析 |
| `process-simulation/` | 流程推演 | 业务流程模拟、方案可行性推演、场景走查 |
| `scope-analysis/` | 影响范围分析 | 需求变更影响评估、模块依赖分析、风险评估 |

## 📝 文件命名规范

```
[日期]-[主题]-[分析类型].md
```

**示例**：

- `20260224-payment-refund-data-analysis.md`
- `20260224-order-flow-process-simulation.md`
- `20260224-user-center-scope-analysis.md`

## 💡 使用建议

1. 每份分析文档应包含：分析目的、分析方法、数据来源、分析结论、行动建议
2. 数据分析建议附上图表（存放至 `assets/diagrams/`）
3. 流程推演建议使用 Mermaid 绘制流程图
4. 影响范围分析建议使用矩阵图评估风险等级

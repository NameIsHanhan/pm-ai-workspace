# 📦 最终交付物（Outputs）

> 本目录存放经过审核、可以对外交付的最终文档和材料。

---

## 📁 子文件夹说明

| 目录 | 用途 | 说明 |
|------|------|------|
| `client-prds/` | 对外交付的 PRD | 提供给客户或合作方的正式需求文档 |
| `presentations/` | 汇报演示材料 | 项目汇报、方案评审、进展演示等 |
| `handoff-docs/` | 交接文档 | 开发交接文档、测试用例、上线清单等 |
| `archive/` | 归档 | 已完成项目的历史交付物 |

## 📝 文件命名规范

```
[模块名]-[文档类型]-v[版本号]-[日期].md
```

**示例**：

- `user-center-prd-v1.0-20260224.md`
- `q1-progress-presentation-20260224.pptx`
- `order-module-handoff-v1.0-20260224.md`

## ✅ 质量标准

交付物在放入本目录前，应确保：

- [ ] 内容完整，无遗漏章节
- [ ] 格式规范，排版整洁
- [ ] 术语统一，表述无歧义
- [ ] 版本号正确标注
- [ ] 已通过内部评审
- [ ] 敏感信息已脱敏（如对外交付）

## 💡 管理建议

1. 对外交付的文档需要特别注意信息安全
2. 交付前建议导出为 PDF 格式，防止格式错乱
3. 重要交付物建议保留修改记录
4. 项目完成后，将所有交付物统一归档至 `archive/`

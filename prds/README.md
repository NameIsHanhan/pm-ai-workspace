# 📄 正式 PRD 输出区（PRDs）

> 本目录存放经过评审的正式 PRD（Product Requirements Document）文档。

---

## 📋 用途说明

- 存放正式版本的 PRD 文档
- 草稿阶段的 PRD 请先放入 `drafts/` 目录
- 评审通过后从 `drafts/` 移入本目录

## 📁 组织方式

按 **模块** 组织文件：

```
prds/
├── user-center-prd-v1.0.md       # 用户中心 PRD
├── order-module-prd-v2.0.md      # 订单模块 PRD
├── payment-prd-v1.0.md           # 支付 PRD
├── archive/                       # 归档目录
│   ├── user-center-prd-v0.9.md   # 历史版本
│   └── ...
└── README.md
```

### 命名格式

```
[模块名]-prd-v[版本号].md
```

## ✅ 审核标准

PRD 进入本目录前须满足以下标准：

### 内容完整性

- [ ] 需求背景与目标
- [ ] 用户故事 / Use Case
- [ ] 功能需求（含业务规则）
- [ ] 字段清单
- [ ] 交互流程图
- [ ] 异常场景处理
- [ ] 非功能需求

### 质量要求

- [ ] 无歧义描述
- [ ] 前后逻辑一致
- [ ] 需求可测试验证
- [ ] 影响范围已评估
- [ ] 关键决策有依据

### 流程要求

- [ ] 已使用三阶段工作流完成
- [ ] 已通过 AI 质量审查（Phase 3 Step 3）
- [ ] 已获得相关方确认

## 💡 管理建议

1. 版本更新时，旧版本移入 `archive/`
2. PRD 文档头部应包含版本号、日期和修订记录
3. 重大变更建议升级主版本号（如 v1.0 → v2.0）
